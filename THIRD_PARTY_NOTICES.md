# Licenses and asset notices

Benga's project code is licensed under GPL-2.0-only; see `LICENSE`.
Third-party materials retain their own terms. The project license does not
relicense upstream assets.

## Iosevka

The embedded Iosevka Tight Soft font subsets use the SIL Open Font License 1.1.
The complete upstream notice is in `assets/fonts/Iosevka/OFL.txt` and is included
in packages as `assets/licenses/Iosevka-OFL.txt`.

## Gogh themes

The imported Gogh color themes use the MIT License, copyright 2024 Gogh.
The complete notice is in `assets/Gogh-LICENSE`, also included in packages.

## Weapon models

The model preparation process is recorded in `tools/prepare_weapon_models.py`.
Upstream authorship, source URL and redistribution terms still need to be
recorded; see `assets/models/NOTICE.txt` (packaged as
`assets/licenses/Models.txt`). Embedding the models does not change their terms.

## Logo and Philly Sans

The outlined Benga wordmark retains references to Philly Sans. Its provenance
and applicable permission still need confirmation. The font's supplied
non-commercial notice is in
`assets/fonts/philly_sans/non_commercial_license.txt`, included in packages as
`assets/licenses/Philly-Sans.txt`. The Philly Sans font binary is not embedded
or included in desktop packages.
