macOS installation script

Installs Benga in ~/Applications and removes quarantine attributes from it

Audio setup

macOS 14.6+ Allow system audio recording when prompted.

Windows Uses the default audio output. Restart Benga after changing the output device or sample rate.

Linux Select your output’s monitor as Benga’s recording source in your audio settings or pavucontrol. PulseAudio and PipeWire’s PulseAudio service are supported.
